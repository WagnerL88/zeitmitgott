upload-fl

Ferramenta interna de publicação de vídeos.

O upload-fl é uma ferramenta de linha de comando de uso interno, executada em uma estação de trabalho própria. Ela cumpre a etapa final de um processo de produção de vídeo: pega o arquivo finalizado e os metadados já escritos para ele e publica no canal do YouTube do próprio operador.

O que ela faz

  • Envia o arquivo de vídeo finalizado para o canal do próprio operador
  • Aplica título, descrição, tags e miniatura já produzidos
  • Agenda a publicação para o horário local do público daquele canal
  • Envia o arquivo de legendas, quando houver

O que ela não faz

  • Não é distribuída nem oferecida a terceiros
  • Não tem usuários além do próprio operador
  • Não coleta, exibe, armazena nem compartilha dados de terceiros
  • Não automatiza o site do YouTube — usa exclusivamente a YouTube Data API v3
